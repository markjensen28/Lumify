🎮  “Mix  Match  Memory  Quest”  
This  is  a  3-card  matching  memory  game  where  players  must  form  a  complete  set :  
✅  1  Term  +  1  Picture  +  1  Description  =  1  Correct  Match  Set  
Example  of  a  correct  set:  
●  Uniform  Mixture  (term)  ●  Salt  Water  (picture)  ●  “Looks  the  same  throughout”  (description)  
 
🧠  GAME  LOOP  (Step-by-Step  Gameplay  
Flow)
 
1.  Start  Phase  
●  Player  enters  the  pixel  lab  room  ●  Grid  of  face-down  cards  appears  (e.g.,  12–18  cards)  ●  Timer  starts  (e.g.,  90  seconds)  
 
2.  Player  Action  Loop  
Player  can  only  flip  3  cards  at  a  time  
Step  1:  Flip  Cards  
●  Player  taps  a  card  →  it  flips  (animation)  ●  Player  flips  up  to  3  cards  
 
Step  2:  System  Check  (Core  Logic)  
After  3  cards  are  flipped:  
👉  The  system  checks:

🧩  CARD  TYPES  (Game  Data  Structure)  
You  will  have  3  categories  of  cards :  
1.  Term  Cards  
●  Uniform  Mixture  ●  Non-uniform  Mixture  
 
2.  Picture  Cards  
●  Orange  Juice  ●  Salt  Water  ●  Sand  and  Water  ●  Fruit  Salad

●  “Looks  the  same  throughout”  ●  “Components  can  be  seen  separately”
